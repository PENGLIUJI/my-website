# 拓客管家 - 家具外勤管理系统原型

这是一个可直接打开的前端原型，用于管理家具门店员工外出扫楼、陌拜、拓客的日报流程。

## 已实现

- 老板端总览：今日拜访数、外勤人数、重点客户数、异常提醒。
- 端口分离：左侧可切换“老板后台”和“员工端”，老板后台看统计、审核、绩效、规则，员工端只做外勤填报和草稿续填。
- 外勤地图：员工位置、路线区域、风险状态。
- 员工端提交：按当前登录账号自动归属员工，不能选择别的员工；员工填报页的老客户回访、小区信息、客户信息、现场情况、凭证与备注都改为手机友好的展开/收起版块，并使用紧凑手机排版。新增客户填写可收起的小区信息；客户模式为“客户类型+客户姓名、房号+客户电话”，师傅/异业模式为“等级+工种/渠道、姓名+电话”；是否添加微信和微信昵称并排；微信头像识别结果放在头像截图右边并使用短状态文案；老客户带出提示改为下方短提示，避免手机上挤成竖排；现场情况、装修进度、停留时长等也尽量并排减少滑动；老客户回访自动带出历史小区房号，不再重复显示小区信息；师傅、异业和渠道不显示小区信息、房号和现场情况。
- 员工端客户跟踪：自动汇总员工扫楼客户，用手机卡片显示“今天要跟、A类重点、无效待审”，点客户可看最近情况和历史记录。
- 老客户回访：使用一个“小区 → 楼栋 → 客户”的多级下拉选择已保存客户后，自动带出楼盘、房号、电话、微信等历史信息，减少重复填写。
- 微信头像识别：员工上传微信头像截图后，系统自动识别并填充客户微信昵称，员工仍可手动修改。
- 草稿保存：员工可先保存草稿，后续继续修改；正式提交后记录锁定，不再开放修改入口。
- 日志审核：搜索、装修进度筛选、照片和定位规则校验。
- 客户池：按拆改、水电、瓷砖、木工、油漆、吊顶、定制安装、软装进场、已入住、暂不清楚等装修阶段分组。
- 员工管理：目标完成率和新增员工。
- 审核规则：照片、定位、最长空档时间等规则可调整。
- 本地存储：刷新页面后保留当前演示数据。
- CSV 导出：导出当日外勤日志。

## 使用

直接用浏览器打开 `index.html`。

后续要上线成真实系统时，需要增加后端服务、员工账号、手机端登录、地图服务、图片上传、权限管理和数据备份。
